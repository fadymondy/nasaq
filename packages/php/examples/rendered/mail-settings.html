DNS checklist

                    
Add these records at your DNS host. Then check again.

                    

                

                            

                                

                                    SPF
                                    Says which servers may send for the domain.
                                

                                                                    
                    Wrong value

                                                            

                                                            

                                    Type
                                    TXT
                                    Name
                                    shop.example.com
                                

                                

    

        

    
    




                                                                    

                                        Found:
                                                                                    v=spf1 +all
                                                                            

                                                                                                                        

        

                            
This record lets any server send for the domain (+all). Use -all or ~all.

            

    

                                                    

                                                                    

                            

                                

                                    DKIM
                                    Signs each message so it cannot be forged.
                                

                                                                    
                    Correct

                                                            

                                                            

                                    Type
                                    TXT
                                    Name
                                    mail._domainkey.shop.example.com
                                

                                

    

        

    
    




                                                                                                                

                                                                    

                            

                                

                                    DMARC
                                    Tells receivers what to do with mail that fails the two above.
                                

                                                                    
                    Wrong value

                                                            

                                                            

                                    Type
                                    TXT
                                    Name
                                    _dmarc.shop.example.com
                                

                                

    

        

    
    




                                                                    

                                        Found:
                                                                                    v=DMARC1; p=none
                                                                            

                                                                                                                        

        

                            
Policy none only monitors. Move to quarantine or reject once reports look clean.
