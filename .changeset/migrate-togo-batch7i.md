Add `SectionBoard`: an ordered set of AI-generated sections. View mode shows only the content; edit mode lets people reorder (drag, or the arrow keys on the handle), edit each section's title, tag, prompt, model and free key/value settings in a dialog, and remove it, with every change announced. Pure helpers `sectionSettingRows`, `sectionSettingsFromRows`, `duplicateSectionSettingKeys`, `boardSectionChanged`.
