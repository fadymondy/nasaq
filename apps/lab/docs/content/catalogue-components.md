# Component catalogue

All {{components}} components, grouped by category. The list is generated from the component manuals, so it is always the current set.

Each entry opens that component's **Docs** page: its manual (when to use it, anatomy, API, accessibility, RTL notes) followed by live stories. The same manual is what the [MCP server](?page=docs-guides-mcp-server) gives an AI assistant.

- **Install one:** the item name is the folder name, for example `npx shadcn@latest add @nasaq/data-table`. See [Install with the shadcn CLI](?page=docs-installation-shadcn-cli).
- **Status.** A badge appears when a component is not yet `stable`: `beta` components work but their API may still move, and `experimental` ones may change or go away.
- **Foundations.** Colour, typography, icons, motion and layout rules are in the **Foundations** section of the sidebar.
- **Full pages.** For whole screens built from these parts, see [Page templates](?page=docs-catalogue-page-templates).
